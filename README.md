# Fwinobox AI

A modern, fast, ChatGPT-style AI assistant with **Obsidian Brain** long-term memory, **Live Multi-Web Absorption**, and universal multilingual fluency, built using **Next.js App Router**, **TypeScript**, **Tailwind CSS**, and **React**.

## Quick Start

Jalankan [Start-Fwinobox.bat](file:///d:/hermes/Start-Fwinobox.bat) atau:

```bash
cd hermes-ai
npm run start
```

Kemudian buka [http://localhost:3000](http://localhost:3000).
